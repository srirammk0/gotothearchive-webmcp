# Deferred and future work

## Intentionally deferred from the current pass

- Voice-note ingestion, transcription, and voice annotations.
- Native Pinterest integration.
- Chrome capture extension.
- Broad connector marketplace.
- Video and audio Workbench review.
- Public community, discovery feed, or social graph.
- Whole-account sharing.
- Team administration beyond core shared-space roles.
- Visible freeform graph exploration.
- Generic built-in AI chat as a primary surface.
- Arbitrary execution of reviewed code.
- Full autonomous taste inference from passive behavior.
- Dark mode.
- Advanced cross-version visual diffing for every artifact type.

These cuts reduce incidental breadth without weakening Archive, Agent Access, Workbench, sharing, provenance, or continual taste learning.

## Foundation that must remain extensible

- Item type registry and multimodal processing adapters.
- Artifact viewer and annotation target adapters.
- Source connector abstraction.
- Task and agent/client identity model.
- Space, region, project, and sharing boundaries.
- Context edges and retrieval scoring signals.
- Taste signal scopes and evidence model.
- Proposal and approval workflows.
- Capability compiler driven by current policy.
- Audit and provenance records.

## Likely next expansions

### Capture and sources

- Browser extension.
- Are.na ingestion.
- Pinterest ingestion where permitted.
- Google Drive.
- GitHub.
- Calendar.
- Notion, Slack, Gmail, and cloud file systems.

### Collaboration

- Richer team roles.
- Shared team taste models.
- Cross-organization artifact review.
- Approval policies and review routing.
- Shared templates and project context packs.

### Workbench

- Video and audio review.
- Rich document redlines.
- Slide and visual diffs.
- Executable development sandboxes with explicit authority.
- Evaluation rubrics and reusable review frameworks.

### Taste intelligence

- Better contextual preference ranking.
- Cross-artifact pattern discovery.
- Personalized agent evaluation.
- Time-aware evolution and conflict resolution.
- Explicit “why this signal changed” comparisons.

### Agent interfaces

- MCP beyond the browser.
- Public APIs and SDKs.
- Direct integrations with agent environments.
- Portable task/context packages.

### Ownership and portability

- Complete export.
- Import and migration tooling.
- Rich retention controls.
- Optional local or private-storage modes.
- Multi-device sync policies.

## Expansion rule

A new capability belongs when it strengthens at least one central loop without obscuring the others:

- Curate context.
- Lend context safely.
- Create and review artifacts.
- Collaborate with people.
- Learn from explicit feedback.

Connector count, modality count, and graph complexity are not success metrics by themselves.
