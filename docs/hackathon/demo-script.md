# GoToTheArchive — WebMCP Challenge demo script

**Target:** 2:10–2:20 · narrated screen recording

## 0:00–0:25 — The problem

**[SHOW: Archive. Move through Work, Inspiration and Personal. Open one visual reference.]**

Context is the biggest problem for agents today. But the context they remember about us is usually hidden in a database we do not own, edit or understand.

And context is only the beginning. What we really want agents to learn is taste: the judgment behind what we keep, reject and ask to change.

## 0:25–0:50 — The thesis

**[SHOW: Archive and an item's design profile.]**

GoToTheArchive is a shared, human-owned Archive for context and taste. I curate the material. I control the boundaries. My agent can work with me, but it never gets an invisible copy of me.

Images, webpages, PDFs, notes and feedback stay visible, organized and useful even when no agent is connected.

**[MENTION, DON'T DEMO: Multimodal references keep provenance; measured palettes come from real pixels; relationships never grant access.]**

## 0:50–1:18 — WebMCP makes it real

**[SHOW: Agent Access, then Agent Lens. Work = suggest changes; Inspiration = view; Personal = none.]**

WebMCP is the key because the agent enters the same interface where I set its scope. For this task, it can read Inspiration and create in Work. Personal is not merely ranked lower — it is unavailable.

Agent Lens makes that live: the tools and schemas change with my choices. The server checks every call again, so the UI and the agent can never drift apart.

**[MENTION, DON'T DEMO: Human access caps agent authority; grants expire and denials are audited.]**

## 1:18–1:43 — From archive to work

**[SHOW: 8× Codex run: inspect scope, retrieve references, create landing page. Cut to the artifact in Workbench.]**

Codex uses those permitted references to build this landing page. The work comes back as a versioned artifact — not a chat blob. Workbench shows what was accessed, what influenced the result and where I can annotate, approve or ask for changes.

## 1:43–2:05 — Taste, then control

**[SHOW: Add one annotation. In Codex, call `trace_artifact_influences`, then `propose_taste_signal`. Open Taste and confirm or edit the proposal. Revoke Inspiration; show Agent Lens lose it.]**

My feedback becomes an evidence-linked Taste proposal, not a secret memory. The agent has to read the evidence and name the pattern; I decide whether it is true, how it is worded and where it applies.

Then I can take access back. Inspiration disappears from the agent's tools and its evidence disappears from agent retrieval — while my human Archive remains intact.

**[MENTION, DON'T DEMO: Silence never confirms a preference; proposals are reversible; revocation does not claim the model forgot what it saw.]**

## 2:05–2:20 — Close

**[SHOW: GitHub for one second, then return to the Archive.]**

GoToTheArchive is not another memory app. It is the place where people own the context that represents them, collaborate with agents through WebMCP, and decide what becomes taste.

We open-sourced the implementation and documented the WebMCP questions we found around multimodal I/O, provenance and revocation.

Your agent should not own a hidden model of you. You should own the Archive.
